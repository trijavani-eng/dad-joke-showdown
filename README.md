## The joke

> My dad says being a dad is a vicious cycle — you blame the kids, the kids blame you, and round and round it goes. Like a bicycle, but with more yelling.

One line, 152 characters: a dad joke with a real pun (vicious cycle / bicycle), a groan, and a straight face.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt`. It is fully deterministic — a constant string, no randomness, no time, no network — so repeated runs produce byte-identical output.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
