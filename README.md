## The joke

> My dad says he doesn't need a smartwatch. He already has me — I remind him of everything, twice, loudly, from the next room.

One line, 124 characters: a dad joke with a straight face, a groan, and no stock pun.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt`. It is fully deterministic — a constant string, no randomness, no time, no network — so repeated runs produce byte-identical output.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
